# Homebrew tap for cdb

[cdb](https://github.com/sriannamalai/CDB.CLI) is an interactive command line client for Apache CouchDB 3.2-3.5.

## Install

```sh
brew install --cask sriannamalai/tap/cdb
```

Or tap first, then install:

```sh
brew tap sriannamalai/tap
brew install --cask cdb
```

## Upgrade

```sh
brew upgrade --cask cdb
```

## Uninstall

```sh
brew uninstall --cask cdb
```

## Platforms

The cask carries release archives for:

- macOS (Darwin), arm64 and amd64
- Linux, arm64 and amd64

## How this tap is maintained

`Casks/cdb.rb` is generated by goreleaser on every CDB.CLI release and must not be edited by hand. Any changes made directly to it will be overwritten on the next release.

On macOS, the cask's post-install hook clears the quarantine attribute from the installed binary so it runs without a Gatekeeper prompt.

Issues with cdb itself, or with this cask, belong on the [main repo](https://github.com/sriannamalai/CDB.CLI/issues).
